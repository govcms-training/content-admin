# Exercise

### Exercise 1

Create a few new pages of content. Make sure that you edit each one a few times, as this creates a revision log that we'll use later.

If you want to add some basic text to help pad out your page, use the handy website [Lipsum](https://www.lipsum.com/feed/html) to provide some placeholder text.

### Exercise 2

Edit a page by accessing the **Content listing page**.

Then edit it again by viewing it and using the **Edit tab** button.

### Exercise 3

Archive a page and try to access it using a different browser or incognito mode. See how it changes.

### Exercise 4

Delete a page and try accessing the URL. You will see a different error message.

### Exercise 5

Use the **Revisions tab** to see the history of your page's changes. View an old revision, compare it against the current revision and then revert it to that old revision.
