# Exercise

### Exercise 1

Upload a media image to the Media Library. A great source of free and royalty-free images can be found at [Pexels](https://www.pexels.com/).

Make sure that you add a descriptive alternative text.

### Exercise 2

Add that media asset to your new page as the banner background AND embedded in a content field.

#### Exercise 3

Use the **file replace** functionality and update your image with a new one via the Media Library, then view your page and see what has changed.
