# Reusing media

Media is stored in the **Media Library** and can easily be **reused anywhere** on your website. As such, you should always check the Media Library to see if what you're about to upload already exists.

{% hint style="info" %}
Media reuse prevents duplicates and ensures consistency.
{% endhint %}

As an example of media assets being reused across the website, while editing a page, I can use the same image in both the **Thumbnail** field and in the **Content** WYSIWYG field.
