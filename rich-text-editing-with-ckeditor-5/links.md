# Links

The icon that looks like a chain link is the **Link** tool. As part of GovCMS, the LinkIt module is provided and enabled on most sites. This module allows you to easily link to any internal page without having to copy and paste the URL.

Simply select the text you want to link, select the **Link** icon, and then start typing in the name of the page you want to link to.

The autocomplete field will provide you options that you can select, and then click the **Insert** button.

<figure><img src="../.gitbook/assets/link.avif" alt=""><figcaption></figcaption></figure>

Alternatively, you can link to any external URL by pasting it in and then clicking the **Insert** button.

<figure><img src="../.gitbook/assets/link-insert.avif" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Avoid using generic phrases like "click here" or "learn more" for links. This provides no context on where the link will take you to, which does NOT meet accessibility standards. (Visually impaired users who use screen reading technology will literally just hear "click here".)
{% endhint %}
