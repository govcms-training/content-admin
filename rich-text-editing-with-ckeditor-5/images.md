# Images

In GovCMS we don't embed images into content by providing a URL to an image, instead we embed a reference to a **Media** entity.

In the below example we've used the Media button, located on the far right of the toolbar, to insert an image from our Media library. However, it hasn't simply uploaded an image to this page, instead it references a Media entity that can be re-used anywhere else on the website.

This approach allows you to maintain a library of images and re-use them consistently without having to source the same image over and over.

More information about [Media](https://app.gitbook.com/s/zAp101XNX82HnyCe3C9U/media-and-files) is covered in the next section.

When embedding images into your website, your developers may have enabled Content Authors to change the **View mode** of the media, so you can change the size of the image.

If this option is available, you'll see a select list under the image when it's selected, which allows you to change the view mode of the image, likely changing its size.
