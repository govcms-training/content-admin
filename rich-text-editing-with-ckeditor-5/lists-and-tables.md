# Lists and tables

### Lists

Lists can be inserted following the same process you'd use for word-processing applications. Select the items and click the **Unordered** or **Ordered** list buttons.

<figure><img src="../.gitbook/assets/Screenshot 2026-06-04 at 2.11.31 pm.png" alt=""><figcaption></figcaption></figure>

Additionally you can increase or decrease the **indent** of the lists using buttons in the toolbar, or by using the tab key while editing.

### Tables

Clicking the Table icon in the toolbar allows you to quickly insert a table up to 10x10.

<figure><img src="../.gitbook/assets/table.avif" alt=""><figcaption></figcaption></figure>

Once the table has been added, you can click anywhere in the table to access additional tools. These include adding header rows and columns, as well as inserting or deleting rows and columns, and merging cells.

<figure><img src="../.gitbook/assets/table-header.avif" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Tables should **ONLY** be used to display tabular data. Do **NOT** use tables as a substitute for a grid layout for text content.
{% endhint %}
