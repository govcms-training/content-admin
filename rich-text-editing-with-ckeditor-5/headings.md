# Headings

The **Paragraph** dropdown option allows you to set heading levels.

Correct use of headings to create structured content not only makes the website easier to read for your users, but also increases your SEO and AI-readability.

To create a heading, simply select some text with your cursor and use the dropdown menu to select the heading level.

If you want to revert a heading to basic text, simply select Paragraph instead of the heading level.
