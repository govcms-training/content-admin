# Publishing responsibilities

By default, GovCMS comes with a standard publishing workflow.

The [workflow](https://app.gitbook.com/s/zAp101XNX82HnyCe3C9U/workflows) system is covered fully later on, however the basics are:

* Authors draft and update content
* Approvers review and publish content (or send it back to Content Authors to update)
* Site Administrators support overall structure and perform basic administrative functions via the user interface (UI) but do not perform development tasks or coding.
