# What this manual covers

This training manual covers the following topics:

* User roles and permissions
* Logging in and the Admin interface
* Understanding the content structure of Drupal
* Creating, managing and publishing content
* The primary WYSIWYG editor available in GovCMS
* Managing media and files
* URL redirects and URL aliases
* Working with menus and information architectutre
* Taxonomy and simple site structure items
* Moderation workflows
* Webforms
* Advanced content editing options
* Accessibility and content governance
* Governance and best practices
* Optional CivicTheme patterns



Each section also contains various exercises to put your new-found knowledge to use.
