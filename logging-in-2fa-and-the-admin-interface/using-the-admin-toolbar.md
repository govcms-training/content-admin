# Using the Admin toolbar

### Hover over menu items to expand menus

The **Admin toolbar** gives you access to a variety of functions. When you hover your mouse over the various menus in the Admin toolbar (without actually clicking on the menus), most of them expand to reveal more options — like the screenshot below.

<figure><img src="../.gitbook/assets/image (14).png" alt=""><figcaption><p>Hovering over Structure, and then Taxonomy</p></figcaption></figure>

Let's try hovering over a top level menu item.

Select **Manage** at the top of the page to ensure you can see the correct menu section, and then hover over the various menus to see their child menu items.

{% hint style="info" %}
The menu items you see may be different to those shown in the above screenshot. This is by design; it’s not a flaw. What you see within the Admin toolbar is based on your role. For example, Site Administrators can access more menu options than Content Authors. This is in line with the user roles and permissions discussed at the beginning of this manual.
{% endhint %}

{% hint style="info" %}
The far left icon in the menu to the left of Content is a direct link to the homepage of your website.
{% endhint %}
