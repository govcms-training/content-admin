* Use either a [URL redirect](../url-aliases-and-redirects/redirects.md) or change the [URL alias](../url-aliases-and-redirects/url-aliases.md) to get the page accessible via **/ap**&#x20;
* Use the **Content** component for the summary text
* Use **Accordion** components for the question and answers
* Use the **Attachment** component for the documents
* Use a **Promo** or **Callout** component for the link with additional text sourced from the summary.
